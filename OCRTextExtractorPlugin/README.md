# OCR文字抽出プラグイン

![Version](https://img.shields.io/badge/version-1.4.0-blue)

AviUtl2 の現在フレーム（既定）または画面全体から指定範囲を取り込み、Windows 標準の OCR 機能で文字を抽出する汎用プラグインです。インターネット接続を使わずに認識できます。

## 主な機能

- 認識元を **AviUtl2 の現在フレーム** と **画面全体をキャプチャ** から選択
- 現在フレームは専用プレビュー上で、画面全体はデスクトップ上で OCR の認識範囲をドラッグ選択
- 選択範囲を半透明の枠で可視化し、範囲選択直後にキャプチャプレビューを更新
- 選択範囲のプレビュー表示と、座標・幅・高さの数値入力による調整
- Windows OCR を使った日本語テキスト認識（インターネット接続不要）
- 認識結果の編集、クリップボードへのコピー、最新 20 件の履歴保存
- 認識文字の自動調整（不要な改行と、日本語に隣接する空白を整形）
- 低解像度画像の補正（OCR 処理用に最大 2 倍へ拡大）
- 指定秒数ごとの自動 OCR
- 認識結果の自動コピー
- 選択範囲を PNG として保存
- 保存した画像をタイムラインへ配置（任意）

## 動作環境

- AviUtl2
- Windows 10 / 11
- Windows の日本語 OCR 言語パック

## インストール

1. [Releases](https://github.com/natuneko722/OCRTextExtractorPlugin/releases) から最新版の ZIP ファイルをダウンロードします。
2. ZIP ファイルを展開します。
3. 展開した `OCRTextExtractorPlugin.aux2` を AviUtl2 の `Plugin` フォルダへコピーします。
4. AviUtl2 を起動し、ウィンドウクライアントの一覧から **OCR文字抽出** を表示します。

> 日本語 OCR 言語パックが入っていない場合は、Windows の **設定 → 時刻と言語 → 言語と地域 → 日本語 → 言語のオプション** から「OCR」を追加してください。

## 使い方

1. 右上の **設定** を開き、必要に応じて認識元を選びます。既定は **AviUtl2 の現在フレーム** です。
2. **範囲選択** を押し、認識する領域をドラッグします。現在フレームでは専用プレビュー上、画面全体キャプチャではデスクトップ上で選択します。
3. **認識** を押すと、選択範囲の認識結果がテキスト欄へ表示されます。
4. 必要に応じて **コピー** または **画像として保存** を使います。

認識範囲は、X・Y・幅・高の入力欄で数値指定することもできます。範囲を選択・調整すると、キャプチャ画像のプレビューも更新されます。認識元を切り替えると、座標系が変わるため範囲を選び直してください。

## 設定

右上の **設定** を押すと、次の項目を変更できます。

### OCR認識

- 認識元
  - **AviUtl2 の現在フレーム**（既定）：元解像度の映像を専用プレビューに表示して範囲を選択します。
  - **画面全体をキャプチャ**：デスクトップ全体を対象に、画面上で範囲を選択します。
- 認識文字の自動調整
  - 単一改行を連結し、空行は段落区切りとして残します。
  - 日本語文字に隣接する半角・全角空白などを削除します。英単語どうしの空白は残します。
- 低解像度画像に対する補正
  - 選択範囲の幅が 1280px 未満、または高さが 720px 未満の場合、OCR 処理用に 2 倍へ拡大します。保存画像やプレビューは変更しません。
- 自動認識の有効化と実行間隔（秒）
- 認識結果の自動コピー

### 画像として保存

- 保存先：開いているプロジェクトファイルと同じフォルダ、または任意のフォルダ
- 保存時にタイムラインへ配置

保存ファイル名は `OCR_プロジェクト名_年月日_時分秒.png` です。同じ秒に重複した場合は `_2`、`_3` のような連番を付け、既存ファイルを上書きしません。プロジェクトが未保存の場合は、保存先の選択を求められます。

## v1.4.0 の主な変更

- AviUtl2 の現在フレームを認識元として選べるようにし、専用プレビューから範囲選択できるようにしました。
- 従来の画面全体キャプチャも、設定から引き続き利用できます。
- 現在フレームの範囲選択中に発生していた描画のちらつきを抑制しました。
- 認識文字の自動調整を改善し、日本語文字の間や前後に OCR が挿入した空白を整形できるようにしました。
- 設定画面とキャプチャプレビューを、ウィンドウサイズ変更時にも安定して再描画するよう改善しました。

## 注意事項

- OCR の精度は、元画像の解像度・文字サイズ・フォント・背景などにより変わります。
- 自動認識は、認識範囲を一度選択してから有効にしてください。認識元を切り替えた後も、範囲を選び直す必要があります。
- 翻訳機能およびテキストオブジェクトの自動作成は、現在のバージョンには含まれていません。
